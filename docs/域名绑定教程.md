# ysgame.xyz 绑定 Vercel 教程

> 目标：让 `https://ysgame.xyz` 直接打开你的数独小游戏
> 前提：① 域名 `ysgame.xyz` 已购买 ② Vercel 项目已部署成功

---

## 总览（就 2 步）

```
第1步：Vercel 项目里添加 ysgame.xyz
第2步：去你买域名的平台，添加 DNS 记录（指向 Vercel）
        ↓
等待几分钟~几小时 → Vercel 显示绿色 ✓ Valid → 完成
```

---

## 第 1 步：Vercel 添加域名（2 分钟）

1. 打开 Vercel 项目页 → 左侧菜单点 **`Domains`**
2. 输入框填 `ysgame.xyz` → 点 **`Add`**
3. Vercel 会弹出需要配置的 DNS 记录，**先别关，截图或抄下来**（每台项目给的值略有不同，以页面显示为准）
   - 通常长这样（**以 Vercel 页面显示为准；新版多为 `216.198.79.1`，旧值 `76.76.21.21` Vercel 也都认**）：
     - `A` 记录：主机 `@` → 值 `216.198.79.1`
     - `CNAME` 记录：主机 `www` → 值 `cname.vercel-dns.com`
4. 点 **`Add` / `Continue`** 确认添加（此时状态是 `Invalid` / `Pending`，正常，配完 DNS 才变绿）

> 小提示：Vercel 会同时建议你加 `www.ysgame.xyz`，选 "Add www.ysgame.xyz" 会自动做重定向，建议加上。

---

## 第 2 步：去注册商配置 DNS（按你买域名的平台选一节）

### 情况 A：在阿里云买的
1. 打开 [阿里云域名控制台](https://dc.console.aliyun.com) → 找 `ysgame.xyz`
2. 点 **「解析」/「DNS 解析」**
3. 点 **「添加记录」**，加两条：
   - 记录类型 `A` | 主机记录 `@` | 记录值 `76.76.21.21` | TTL 默认
   - 记录类型 `CNAME` | 主机记录 `www` | 记录值 `cname.vercel-dns.com` | TTL 默认
4. 保存

### 情况 B：在腾讯云（DNSPod）买的
1. 打开 [DNSPod 控制台](https://console.dnspod.cn) → 域名 `ysgame.xyz`
2. 点 **「解析」** → **「添加记录」**
3. 同样加两条（A 记录 `@`→`76.76.21.21`；CNAME `www`→`cname.vercel-dns.com`）
4. 保存

### 情况 C：在 Namecheap 买的
1. 登录 Namecheap → **Domain List** → `ysgame.xyz` 右边 **Manage**
2. 左侧 **Advanced DNS** → **Add New Record**
3. 加：
   - 类型 `A Record` | Host `@` | Value `76.76.21.21`
   - 类型 `CNAME Record` | Host `www` | Value `cname.vercel-dns.com`
4. Save

### 情况 D：在 Cloudflare 买的 / 用 Cloudflare 托管 DNS
1. 登录 Cloudflare → 站点 `ysgame.xyz` → **DNS** → **Records**
2. 加：
   - `A` | `@` | `76.76.21.21` | 代理状态可开（橙色云）也可关
   - `CNAME` | `www` | `cname.vercel-dns.com`
3. 确认 Nameservers 是 Cloudflare 给的那两个（在注册商处把 NS 改成 Cloudflare）

---

## 第 3 步：等待生效 + 验证

1. 回到 Vercel `Domains` 页面，刷新
2. 域名状态从 `Invalid` / `Pending` 变成 **绿色 ✓ Valid**（表示 DNS 已生效、证书已签发）
3. 浏览器打开 `https://ysgame.xyz` → 游戏出现 ✅

> DNS 全球传播通常需要 **几分钟到 24 小时**，国内一般 10~30 分钟就好。耐心等，别反复改。

## 常见问题

**Q：一定要配 www 吗？**
不强制，但建议加。加了用户输 `www.ysgame.xyz` 也能访问（Vercel 自动重定向到主域名）。

**Q：在国内注册商买的 .xyz 要备案吗？**
**不用备案**。因为 Vercel 服务器在境外，国内"域名备案"只针对**放在中国大陆的服务器**。你这情况永不备案。
（注册商可能要求"实名认证"，那是买域名时的步骤，几分钟传身份证，≠ 备案，已实名就忽略。）

**Q：改了 Vercel 项目名之后，原来的 .vercel.app 域名还能用吗？**
不一定。项目改名后 Vercel 会分配新的生产域名，旧的可能保留也可能失效，以
「Settings → Domains」里列出的为准。`ysgame.xyz` 是你自己绑的域名，不受项目改名影响。

**Q：状态一直 Invalid 怎么办？**
- 检查 DNS 记录的值是否和 Vercel 页面**完全一致**（别抄错 IP）
- 确认记录已"保存"并生效
- 等够时间再刷新 Vercel 页面
- 仍不行：把 Vercel Domains 页面截图发我
