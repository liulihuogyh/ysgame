# Google AdSense 接入指南

## 一、申请 Google AdSense

### 1. 前置条件
- ✅ 拥有 Gmail 账号
- ✅ 网站已部署上线（有可访问的URL）
- ✅ 网站有原创内容（数独游戏本身就是原创内容）
- ✅ 网站有一定流量（建议至少有100+ PV/天再申请）

### 2. 申请步骤

#### 第一步：注册 AdSense
1. 访问 [Google AdSense](https://www.google.com/adsense/)
2. 点击"开始使用"
3. 填写你的网站URL（例如：https://your-domain.vercel.app）
4. 填写收款信息（姓名、地址、邮编等）
5. 接受服务条款

#### 第二步：添加广告代码
1. AdSense会给你一段验证代码，类似：
```html
<script async src="https://pagead2.googlesyndication.com/pagead/js/adsbygoogle.js?client=ca-pub-1234567890123456"
     crossorigin="anonymous"></script>
```

2. 将这段代码复制，粘贴到 `index.html` 的 `<head>` 标签中
3. 替换 `index.html` 第18行的注释内容

#### 第三步：等待审核
- 审核时间：1-2周
- 审核期间网站需要保持正常访问
- 确保网站内容原创、无违规内容

### 3. 创建广告单元

**审核通过后**：
1. 登录 AdSense 后台
2. 点击"广告" → "按广告单元"
3. 创建"展示广告"
4. 选择"自适应"尺寸
5. 复制广告代码

**广告代码示例**：
```html
<ins class="adsbygoogle"
     style="display:block"
     data-ad-client="ca-pub-1234567890123456"
     data-ad-slot="9876543210"
     data-ad-format="auto"
     data-full-width-responsive="true"></ins>
<script>
     (adsbygoogle = window.adsbygoogle || []).push({});
</script>
```

### 4. 替换广告位

在 `index.html` 中找到两个广告容器：
- 第一个：游戏下方横幅广告（约第97行）
- 第二个：页面底部广告（约第170行）

将注释内容替换为你的广告代码。

## 二、备选方案：打赏/内购

### 方案1：简单收款码（手动）

**优点**：零门槛，立即可用
**缺点**：需要手动发放道具

**实现步骤**：
1. 准备支付宝/微信收款码图片
2. 创建打赏弹窗

在 `index.html` 的 `</footer>` 前添加：

```html
<!-- 打赏弹窗 -->
<div class="modal" id="donation-modal">
  <div class="modal-content">
    <span class="close-modal">×</span>
    <h2>☕ 支持我们</h2>
    <p>如果你喜欢这个游戏，可以请开发者喝杯咖啡</p>
    
    <div style="margin: 20px 0;">
      <h3>购买提示包</h3>
      <p><strong>¥3 = 50次提示</strong></p>
      <img src="assets/images/alipay-qr.png" alt="支付宝收款码" style="max-width: 200px;">
    </div>
    
    <p style="font-size: 0.9rem; color: #A0AEC0; margin-top: 20px;">
      支付后请截图并添加微信：<strong>your-wechat-id</strong><br>
      客服确认后立即发放提示次数
    </p>
  </div>
</div>

<script>
function showDonation() {
  document.getElementById('donation-modal').classList.add('show');
}

// 关闭打赏弹窗
document.querySelector('#donation-modal .close-modal').addEventListener('click', () => {
  document.getElementById('donation-modal').classList.remove('show');
});
</script>
```

### 方案2：虎皮椒个人免签支付（自动）

**优点**：自动到账，自动发放道具
**缺点**：需要配置后端接口（可用免费云函数）

**接入步骤**：
1. 注册 [虎皮椒](https://www.xunhupay.com/)
2. 获取API密钥
3. 创建支付接口（简化版可用客户端直接调用）

**示例代码**（添加到 `game.js` 末尾）：

```javascript
// 购买提示功能
function buyHints(amount) {
  // 这里对接虎皮椒支付接口
  const payUrl = `https://api.xunhupay.com/payment/do.html?
    appid=YOUR_APP_ID&
    amount=${amount}&
    title=购买提示包&
    notify_url=YOUR_NOTIFY_URL`;
  
  // 打开支付页面
  window.open(payUrl, '_blank');
  
  // 监听支付成功（实际需要后端验证）
  // 支付成功后增加提示次数
  // game.hints += 50;
  // game.saveGameState();
}
```

### 方案3：爱发电（推荐个人创作者）

**平台**：[爱发电](https://afdian.net/)
**优点**：

**步骤**：
1. 注册爱发电账号

## 三、收益预期

### Google AdSense 收益计算

**基础数据**（假设）：
- DAU（日活用户）：500
- 人均PV（页面浏览）：3次
- 日PV = 500 × 3 = 1500
- 月PV = 1500 × 30 = 45,000

**广告收益**：
- RPM（千次展示收入）：¥10-30（取中间值¥20）
- 月收入 = 45 RPM × ¥20 = **¥900**

**DAU提升后**：
- DAU 1000 → 月入 ¥1,800
- DAU 2000 → 月入 ¥3,600
- DAU 5000 → 月入 ¥9,000

### 内购/打赏收益

**转化率假设**：
- 付费用户比例：1-3%
- 人均付费：¥3-10

**月收益计算**（DAU 500）：
- 月活用户：500 × 30 = 15,000
- 付费用户：15,000 × 2% = 300人
- 月收入：300 × ¥5 = **¥1,500**

### 组合方案收益

**广告 + 内购双管齐下**：
- 广告收入：¥900/月
- 内购收入：¥1,500/月
- **总收入：¥2,400/月**

## 四、优化建议

### 1. 提升广告点击率（CTR）

**广告位置优化**：
- ✅ 游戏完成后展示（用户处于放松状态，更易点击）
- ✅ 游戏暂停时展示插屏广告
- ❌ 避免在游戏中频繁弹广告（影响体验）

**A/B测试**：
- 测试不同广告位置的收益
- 测试广告尺寸（横幅 vs 矩形）

### 2. 增加付费点

**除了提示包，还可以卖**：
- 🎨 主题皮肤包（¥1-3）
- 🔕 去广告永久会员（¥6）
- ⚡ VIP月卡（¥9.9/月）：无限提示 + 无广告 + 专属皮肤
- 🏆 解锁高级统计功能（¥3）

### 3. 提升用户留存

**每日回归激励**：
- 连续登录送提示次数
- 每日一题挑战（完成送奖励）

**社交裂变**：
- 分享给好友，双方都得提示次数
- 排行榜（激发竞争）

## 五、注意事项

### AdSense 违规行为（禁止）

❌ **自己点击自己的广告**（会被封号）
❌ **诱导用户点击广告**（"点击广告支持我们"）
❌ **刷流量**（使用机器人或流量交换）
❌ **成人/暴力/版权侵权内容**

### 合规运营

✅ 提供真实原创内容
✅ 明确隐私政策（收集哪些用户数据）
✅ 遵守广告投放规范
✅ 用户体验优先（不要广告影响游戏）

## 七、问题答疑

**Q: 个人能申请 AdSense 吗？**
A: 可以！不需要企业资质，个人即可申请。

**Q: 多久能收到第一笔广告费？**
A: AdSense 每月结算，达到 $100（约¥700）门槛后次月15号左右到账。

**Q: 审核不通过怎么办？**
A: 常见原因：流量太少、内容不够、违反政策。优化后可重新申请。

**Q: 网站没备案能申请吗？**
A: 可以！AdSense 不要求网站备案，只要内容合规即可。

**Q: 收益怎么提现？**
A: 绑定银行卡（支持国内银行），美元自动结汇为人民币到账。
