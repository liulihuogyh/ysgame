## 五、新游戏的接入步骤

1. 新建 `games/<slug>/`：`index.html` + `css/style.css` + `js/<slug>.js`。规则/状态模型较重的游戏可再拆一个纯逻辑文件（如 `js/xiangqi-rules.js`、`js/cube-core.js`），**必须在 `index.html` 里排在游戏脚本之前**才生效，也便于单独用 Node 自测。**同一目录只允许一个写者**：曾出现两个 agent 并发覆盖同一份 `js/<slug>.js`，一会儿自包含、一会儿依赖纯逻辑模块，而 `index.html` 没同步，导致页面因 `CubeCore` 未加载而安静退出、开局不写存档。
2. 复用根 `css/style.css` 里的通用组件：`.g-head`、`.g-title`、`.g-tagline`、`.g-hud`、`.hud-box`、`.seg`、`.g-btn`、`.result`、`.g-hint`。游戏自己的 CSS 只写棋盘、棋子、专属动效。
3. `js/i18n.js` 加 `g<slug>` 字典（中英各一套），`<body data-dict="g<slug>">`；`js/sound.js` 加一套主题与 ALIAS。
4. 脚本顺序：`i18n.js` → `common.js` → `sound.js` → `share.js` →（可选纯逻辑文件）→ 游戏脚本。
5. 大厅：在 `index.html` 与 `en/index.html` 的 `#hallGrid` 里加卡片，并写 `data-cat`（puzzle / arcade / board / casual）。
6. 从 `#hallChips` 里删掉这款的 chip，`<b id="soonCount">` 的数字减一。
7. 帮助页加规则、隐私页加 localStorage 键、`sitemap.xml` 加页面、`docs/og-cards.html` 加一张分享图。
8. 本文件里把状态改成 ✅，并把「待做」计数减一。
