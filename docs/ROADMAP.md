## 五、新游戏的接入步骤

1. 新建 `games/<slug>/`：`index.html` + `css/style.css` + `js/<slug>.js`。
2. 复用根 `css/style.css` 里的通用组件：`.g-head`、`.g-title`、`.g-tagline`、`.g-hud`、`.hud-box`、`.seg`、`.g-btn`、`.result`、`.g-hint`。游戏自己的 CSS 只写棋盘、棋子、专属动效。
3. `js/i18n.js` 加 `<slug 前缀>` 字典（中英各一套），`<body data-dict>`。
4. 脚本顺序：`i18n.js` → `common.js` → `share.js` → 游戏脚本。
5. 大厅：在 `index.html` 与 `en/index.html` 的 `#hallGrid` 里加卡片，并写 `data-cat`（puzzle / arcade / board / casual）。
6. 从 `#hallChips` 里删掉这款的 chip，`<b id="soonCount">` 的数字减一。
7. 帮助页加规则、隐私页加 localStorage 键、`sitemap.xml` 加页面、`docs/og-cards.html` 加一张分享图。
8. 本文件里把状态改成 ✅，并把「待做」计数减一。
