# 数独游戏项目 - README

## 🎮 项目简介

这是一个完整的在线数独游戏项目，专为个人开发者设计，零门槛上线，快速变现。

**特点**：
- ✅ 纯前端实现，无需后端服务器
- ✅ 响应式设计，手机/电脑完美适配
- ✅ 莫兰迪配色，界面简洁美观
- ✅ 5种难度，从入门到专家
- ✅ 完整的游戏功能（提示、撤销、检查、进度保存）
- ✅ 预留广告位，接入 Google AdSense 即可变现

## 🛠️ 技术栈

- **前端**：原生 HTML5 + CSS3 + JavaScript (ES6+)
- **算法**：回溯法生成数独，DLX求解
- **部署**：Vercel（免费托管）
- **统计**：Google Analytics（可选）
- **变现**：Google AdSense

**为什么不用框架？**
- 包体积小（< 100KB）
- 加载速度快（< 1秒）
- 兼容性好
- 适合新手学习
