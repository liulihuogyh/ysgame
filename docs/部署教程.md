## 🚀 第一步：上传代码到 GitHub

### 1.1 创建 GitHub 账号

1. 访问 [GitHub.com](https://github.com/)
2. 点击右上角 "Sign up"
3. 填写邮箱、密码、用户名
4. 验证邮箱

### 1.2 创建新仓库

1. 登录后，点击右上角 "+" → "New repository"
2. 填写信息：
   - **Repository name**: `ysgame`（仓库名）
   - **Description**: "休闲数独小游戏"
   - **Public**（公开，免费）
   - ✅ 勾选 "Add a README file"
3. 点击 "Create repository"

### 1.3 上传代码

**方法1：网页直接上传（推荐新手）**

1. 在仓库页面，点击 "Add file" → "Upload files"
2. 将整个 `ysgame` 文件夹拖拽到浏览器
3. 等待上传完成
4. 在下方填写提交信息："Initial commit - 上传数独游戏代码"
5. 点击 "Commit changes"

**方法2：使用 GitHub Desktop（推荐熟悉图形界面的）**

1. 下载 [GitHub Desktop](https://desktop.github.com/)
2. 安装并登录
3. 点击 "File" → "Clone repository" → 选择刚创建的仓库
4. 将 `ysgame` 文件夹的所有文件复制到克隆的目录
5. 在 GitHub Desktop 中写提交信息，点击 "Commit to main"
6. 点击 "Push origin" 上传

### 1.4 验证上传成功

回到 GitHub 仓库页面，刷新，应该能看到：
```
ysgame/
├── css/
│   └── style.css
├── js/
│   ├── sudoku.js
│   └── game.js
├── assets/
├── index.html
└── 其他文件...
```

## 🌐 第二步：部署到 Vercel

### 2.1 注册 Vercel

1. 访问 [Vercel.com](https://vercel.com/)
2. 点击 "Sign Up"
3. **选择 "Continue with GitHub"**（用 GitHub 账号登录，方便关联）
4. 授权 Vercel 访问你的 GitHub

### 2.2 导入项目

1. 登录后，点击 "Add New..." → "Project"
2. 在列表中找到 `ysgame` 仓库
3. 点击 "Import"
4. 配置页面：
   - **Framework Preset**: 选择 "Other"
   - **Root Directory**: 保持默认 `./`
   - **Build Settings**: 不用改（我们是纯静态网站）
5. 点击 "Deploy"

### 2.3 等待部署完成

- 大约 30 秒后，会看到 "Congratulations! 🎉"
- 你会得到一个免费域名，如：`ysgame-abc123.vercel.app`
- 点击 "Visit" 测试你的游戏！

## 🎯 第三步：绑定自定义域名（可选但推荐）

### 3.1 购买域名

**推荐平台**：
- 国内：[阿里云](https://wanwang.aliyun.com/)（需要实名）
- 国际：[Namecheap](https://www.namecheap.com/)（不需要实名）

**域名选择建议**：
- `sudoku-relax.com`（数独解压）
- `jieshu.fun`（解数趣）
- `easy-sudoku.com`（简单数独）

**价格**：
- `.com` 域名：¥50-80/年
- `.fun` `.games` 域名：¥20-50/年

### 3.2 配置域名解析

**在阿里云（或你购买域名的平台）**：

1. 进入"域名控制台"
2. 找到你的域名，点击"解析"
3. 添加两条记录：

| 类型 | 主机记录 | 记录值 | TTL |
|------|---------|--------|-----|
| CNAME | @ | cname.vercel-dns.com | 600 |
| CNAME | www | cname.vercel-dns.com | 600 |

### 3.3 在 Vercel 绑定域名

1. 回到 Vercel 项目页面
2. 点击 "Settings" → "Domains"
3. 输入你的域名（如 `sudoku-relax.com`）
4. 点击 "Add"
5. 等待 DNS 生效（通常 10 分钟内）

**验证成功**：
- 访问你的域名，能看到游戏即成功！
- Vercel 会自动配置 HTTPS（免费 SSL 证书）

### 5.1 修改代码后如何更新？

**方法1：GitHub 网页编辑**
1. 在 GitHub 仓库找到要改的文件
2. 点击文件，点击右上角 "铅笔" 图标编辑

**方法2：GitHub Desktop**
1. 在本地修改文件
2. 打开 GitHub Desktop，会显示改动
3. 填写提交信息，点击 "Commit to main"
4. 点击 "Push origin"
5. Vercel 自动部署

### 5.2 查看部署状态

1. 登录 Vercel
2. 进入你的项目
3. 点击 "Deployments" 查看部署历史
4. 每次 GitHub 有新提交，Vercel 都会自动部署

## 📊 第六步：接入统计和广告

### 6.1 Google Analytics（可选，用于统计访问数据）

1. 访问 [Google Analytics](https://analytics.google.com/)
2. 创建账号和媒体资源
3. 获取跟踪代码（类似 `G-XXXXXXXXXX`）
4. 在 `index.html` 底部添加：

```html
<!-- Google Analytics -->
<script async src="https://www.googletagmanager.com/gtag/js?id=G-XXXXXXXXXX"></script>
<script>
  window.dataLayer = window.dataLayer || [];
  function gtag(){dataLayer.push(arguments);}
  gtag('js', new Date());
  gtag('config', 'G-XXXXXXXXXX');
</script>
```

5. 提交到 GitHub，等待自动部署

### 6.2 Google AdSense（参考《广告接入指南.md》）

**申请前提**：
- 网站已上线
- 有一定流量（建议 DAU > 100）
- 运营 1-2 周后再申请

**申请流程**：
1. 访问 [Google AdSense](https://www.google.com/adsense/)
2. 填写网站 URL 和联系信息
3. 将验证代码添加到 `index.html` 的 `<head>` 部分
4. 等待审核（1-2 周）
5. 审核通过后，替换广告位代码

## 🆘 常见问题

### Q1: Vercel 部署失败怎么办？
**A**: 检查以下几点：
- `index.html` 是否在根目录
- 文件名是否正确（区分大小写）
- 查看 Vercel 部署日志的报错信息

### Q2: 域名解析不生效？
**A**: 
- DNS 生效需要 10 分钟到 24 小时
- 清除浏览器缓存重试
- 用 [DNS 查询工具](https://www.nslookup.io/) 检查解析状态

### Q3: 手机访问样式乱了？
**A**: 
- 确认 `index.html` 中有 `<meta name="viewport"...>` 标签
- 清除手机浏览器缓存
- 在浏览器开发者工具中模拟移动设备测试

### Q4: 游戏进度丢失了？
**A**: 
- localStorage 被清除会丢失进度
- 隐私模式/无痕模式不保存 localStorage
- 后续可以加云端存储功能

### Q5: Vercel 免费版够用吗？
**A**: 
- 免费版额度：100GB 流量/月
- 够 5000-10000 DAU 使用
- 超出后可以升级 Pro 版（$20/月）或优化 CDN
