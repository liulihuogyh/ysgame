## 🚀 使用流程

### 第1步：上传到GitHub（手动，5分钟）
按照 `GitHub上传教程.pdf` 操作（带截图）

### 第2步：导入Vercel（半自动，3分钟）
1. 登录Vercel
2. 点击"Import Git Repository"
3. 选择你的仓库
4. 点"Deploy"（配置已自动读取）

### 第3步：域名配置（可选，工具辅助）
运行 `域名配置生成器.html`：
- 输入你的域名
- 自动生成DNS记录
- 复制到域名管理后台

### 第4步：推广素材生成（全自动）
运行 `推广素材生成器.html`：
- 输入游戏链接
- 一键生成50条文案
- 导出为Excel表格
